B - Project

1. Calculator

Building this project you will learn to design a calculator which performs different operations and display results on the screen. Your calculator will have a menu with the different options.

2. Number Guessing

The program generates a random number from any range that is specified and the user must guess the number after a hint from the computer. Every time a user’s guess is wrong they are prompted with more hints to make it easier for them to guess the number but at the cost of reducing the score. The clue might be any math clue like multiples, divisible, greater or smaller, or a combination of all.

3. Rock Paper Scissors

Build this popular game. You can play against the computer or 2 players. Here some ideas of functions you can design.

  • a random function: to generate rock, paper, or scissors.
  • result function: to declare the winner of the round.
  • scorekeeper: to keep track of the score.

4. Currency Converter

The project convert currencies from one unit into another. For example, converting Indian rupee to USD or euro. You have 2 options: option 1 - from the menu you will choose one currency and will introduce the amount and then you will see the conversion in all other currencies. Option 2 - choose 2 currencies from a list and convert the money .

5. User and Password

Write a password generator. Be creative with how you generate passwords - strong passwords have a mix of lowercase letters, uppercase letters, numbers, and symbols. The passwords should be random, generating a new password every time the user asks for a new password. Create a menu with different options. User can choose the settings for his/her password (lenght, structure ...) and add an option where he/she can remember it with the help of the words he gave as an input.

6. Login page

The Login page allows a user to gain access to your system. The user will authenticate on this page, typically by entering a username and password.

The login page will have at least next options:

  • Authenticate the user
  • Create new user & password
  • Reset your password
  • Remmember your password

REQUIREMENTS

1. Add a menu to your progran with different options. Last option must be EXIT.
2. Check all possible options in your program. DEPURATION STAGE!
3. Use loops, functions, different types of data, libraries, etc.
4. Comment your code. Use #
5. Don't copy from Internet the code!

  • Classwork: based on daily observation
