Choose your option:

1. Number Guessing Game (Difficulty +)

The program generates a random number from any range that is specified and the user must guess the number after a hint from the computer. Every time a user’s guess is wrong they are prompted with more hints to make it easier for them to guess the number but at the cost of reducing the score. The clue might be any math clue like multiples, divisible, greater or smaller, or a combination of all.

2. Hangman (Difficulty ++)

The core concepts you have to use while developing this project are variables, random, integer, strings, char, input and output, and boolean. In the game, users have to enter letter guesses, and each user will have a limited number of guesses (a counter variable is needed for limiting the guesses). The You can create a pre-organized list of words that users can grab words from (create a List). Also, you must include specific functions to check whether or not a user has entered a single letter or if the input letter is in the hidden word, so if the user has actually inputted a single letter, and to print the correct outcomes (letters).

3. Agenda (Difficulty ++)

Everyone uses an agenda to save contact details, including name, address, phone number, and even email address. The main objective of this project is to generate a contact book using python where users can add a new contact, edit, or delete existing contacts and view the details of all their contacts. The application should also allow users to update contact information, delete contacts, and list saved contacts.

Use Python List methods to manipulate the data (insert, update, delete, consult).

4. Car Booking system (Difficulty +++)

You have to design a python program to manage a car booking system. Your system should have the next options:

1. Add a new car from your system 2. Delete a car from your system 3. Consult the cars available 4. Make a reservation - Book a car 5. Return a car 6. Modify a reservation 7. Consult a price for a booking depending on the number of days (all cars same price) 8. Others than you consider interesting

You need to store:

  • A list of all your cars. And for each Car you store: Brand, car plate, color
  • All the Bookings with: customer name, contact phone, car plate, initial and final date, price based on the number of days booked.

First of all you have to think what data structure is more suitable to manage the information. You need to store information about each car and booking, and keep it in order to delete, modify or consult.

Use Python List methods to manipulate the data (insert, update, delete, consult).

5. Currency Converter (Difficulty ++) The project convert currencies from one unit into another. For example, converting Indian rupee to USD or euro. You have 2 options:

  • Option 1 - from the menu you will choose one currency and will introduce the amount and then you will see the conversion in all other currencies.
  • Option 2 - choose 2 currencies from a list and convert the money .

Use Python List methods to manipulate the data (insert, update, delete, consult).

Create a list or dictionary where you store all your conversions, so the user can update, add, delete or consult the currencies. Here an example:

dict = {'EUR': 1, 'USD': 1.09, 'GBP': 0.83}

You can access to the values with dict[USD] or, dict[EUR]

6. User and Password (Difficulty ++)

Write a password generator. The user can choose the lenght and options to generate passwords - lowercase letters, uppercase letters, numbers, and symbols.

With all the options, the computer will generate a new password.

Create a menu with different options. User can choose the settings for his/her password (lenght, structure ...) and add an option where he/she can remember it with the help of the words he gave as an input.

Use Python List methods to manipulate the password (insert new user-password, update, delete, consult).

7. Login page (Difficulty ++) The Login page allows a user to gain access to your system. The user will authenticate on this page, typically by entering a username and password.

The login page will have at least next options:

  • Authenticate the user
  • Create new user & password
  • Reset your password
  • Remmember your password

Use Python List or Dictionary methods to manipulate the data (insert, update, delete, consult).

For example, you can define your dictionary as:

userspass = { 'user1':'pass1', 'user2':'pass2', 'user3':'pass3' }
